Arch Linux, but with a friendlier bite.

barkOS is a Linux distribution that makes Linux accessible to everyone, without giving up reliability or control.

Follow on GitHub See the roadmap

In development. No stable release yet.

Spend less time fixing your system and more time using it.

barkOS is approachable if you're new to Linux and flexible enough if you've been here for years.

What it does

Good dog. Knows three tricks.

  • Sit.

    Graphical installer

    barkOS installs through a graphical installer, so getting started doesn't mean setting everything up by hand.

  • Stay.

    Stable, streamlined desktop

    barkOS focuses on usability and stability, with a streamlined desktop experience.

  • Roll over.

    Snapper snapshots and rollback

    Snapper saves filesystem snapshots of your system. If a change goes badly, you can roll back instead of starting over.
